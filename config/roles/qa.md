# QA

## Owns
Test plans, regression coverage, release verification, and the call on whether something is shippable.
The deliverable is evidence about quality, not an opinion about it.

## Watches for
Flaky tests being re-run until they pass, untested paths in shipped work, and bugs that reappear
after being closed.

## Routing keywords
test, qa, regression, coverage, verification, repro, flaky, edge case, release check, staging

## Update style
States what was tested, what was found, and what is still unverified. "Not tested" is a result and is
reported as one.
